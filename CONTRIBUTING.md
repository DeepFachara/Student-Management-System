# Contributing to Student Management System

Thank you for your interest in contributing to the Student Management System.

## Getting Started

Before making changes, make sure you have:

- Git installed
- Node.js installed
- npm installed

Clone the repository:

```bash
git clone https://github.com/Vish0523/Student-Management-System.git

Move into the project directory:

cd Student-Management-System

Install the project dependencies:

npm install
Creating a Branch

Do not make changes directly on the main branch.

Create a separate branch for your work.

For documentation changes:

git checkout -b docs/<description>

For new features:

git checkout -b feature/<description>

For bug fixes:

git checkout -b fix/<description>
Making Changes
Make the required changes.
Test the application.
Check that existing functionality is not affected.
Keep changes focused and easy to understand.
Commit Guidelines

Use clear and meaningful commit messages.

Examples:

docs: improve README
docs: add contribution guidelines
docs: add issue template
feat: add new functionality
fix: correct application issue
Pull Request Guidelines

Before creating a pull request:

    Make sure your changes are complete.
    Test the application.
    Check the changed files.
    Write a clear pull request description.
    Explain what was changed and why.
    Reporting Issues

When reporting a problem, provide:

    A clear description of the issue
    Steps to reproduce the problem
    Expected behavior
    Actual behavior
    Relevant error messages
    Screenshots if applicable
    Code and Documentation Quality

Please keep contributions:

    Clear
    Simple
    Well organized
    Properly documented
    Consistent with the existing project

Thank you for contributing!
